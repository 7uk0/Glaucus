To start. This guide assumes you already have a Frontier Dev environment set up. On guides how to do that - ask for assistance in Discord #development channel.

Now. Let’s start.

Before going into coding in anything - you need to find music to add (unless you already have something in mind). BUT. It must be free to use under Creative Commons license (generally it’s CC-BY-3.0 or CC-BY-4.0). Make sure music is clearly labeled and it is free to use, store and distribute. You may use any archive of free music or sites such as Soundcloud or Free Music Archive

N.B.: do note. Royalty free not necessary means free to use. Also ‘personal licenses’ or ‘internal guidelines’ (such as Runescape) are not covered. It needs explicitly be under CC with permission to store, playback, etc.

Done that, download music (do note, if there is no easy way to download and you need to use some tool to rip it from a website - something is wrong) and then convert into mono OGG format. Easiest way to do so is to use Audacity

And now finally you can start coding.

For starters drop your audio file into Resources/Audio/_NF/Jukebox/

After that go to the file Resources/Audio/_NF/Jukebox/attributions.yml (same folder) and add attributions in the format as below

files - It MUST contain correct and full name of the file

license - type of license used (consult this block for correct formatting\naming)

copyright - name of the track and by whom. As addition - add what has been changed (as example on screenshot it was converted to mono OGG)

source - proper link where you found it. Do not provide a direct download link, it is so we can verify music is correctly licensed and people can check out author(s) using it.


Next, go to Resources/Prototypes/_NF/Catalog/Jukebox/Standard.yml Here we essentially add your track to the Jukebox

type - where we add it (jukebox, duh!)

id - identifier for your track. Must be unique, but please not track1, track2, etc

name - how it will show up in the Jukebox. Please follow Author - Song Name format

path - path to your file you’ve uploaded earlier


And this is pretty much it. Now the important part - you MUST load into your Dev environment and check that the song you’ve just added is actually there, that it correctly plays, etc. Only after that you can either proceed with adding the next song or making PR for review. As a personal note - do not do more than 1 song at the time (as in - upload and check) and do not try to add the whole album. Add it in a way that you feel Jukebox listeners would be glad to have it.
