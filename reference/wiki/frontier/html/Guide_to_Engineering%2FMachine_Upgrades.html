Machine Upgrades[edit]


In frontier, some machines built from machine parts (capacitors, manipulators, matter bins and batteries) can be upgraded by replacing the default components with higher tier ones.

Things that look like upgradable components but aren't[edit]

Beakers can be used interchangeably (small beaker, large beaker, cryostatis beaker, bluespace beaker) in the construction of several machines, such as techfabs. The type of beaker used doesn't appear to cause a difference in the amount of lube / glue a given lathe can hold, not in other machines tested so far.

Flatpacking[edit]

A flatpacked machine is always deployed with tier 1 components, but can be upgraded after deployment.

Acquiring components[edit]

Tier 1 components are available at the Autolathe, Engineering Techfab, some tool vendors

Tier 2 and 3 components are obtained through science (research, then print at the protolathe), engineering techfab, salvaging, expeditions, and other activities.

Tier 4 components are not available through science, and are only found through expeditions, rare salvage, and other activities.

Machine upgrade process[edit]

Machines which use capacitors, manipulators, matter bins or batteries as part of their construction sequence can be upgraded by removing the current parts and replacing them with higher tier parts. For most machines, a Rapid Parts Exchange Device (RPED) can be used to insert the upgraded machine parts and remove the obsolete ones. Some machines may require deconstruction and reconstruction with the new parts. When building a new machine from scratch, you can simply use the upgraded parts during the construction sequence.

Manual machine upgrade[edit]

To upgrade a machine manually, you need to deconstruct it until the machine board and components pops out. For most machines, the tool sequence is:

  • screwdriver (opens the maintenance panel)
  • crowbar (puts the machine into the "construction finished" state
  • crowbar (removes the board and components)

At this point, you should have a completed machine frame (with wires), a machine board, and a pile of other components.

  • Insert the machine circuit board
  • Insert the new upgraded components (Capacitors, Manipulators, matter bins, batteries) and non-upgradable components (beakers, cables, steel, glass, etc... according to the circuits board's requirements) until you receive the "construction completed" message
  • Screwdriver to finalize construction

RPED upgrades[edit]

A Rapid Parts Exchange Device (RPED) can be used to upgrade a machine without deconstructing it. The RPED acts as a container for machine parts, and as a tool to replace them. While holding a RPED, click the ground to collect all nearby machine parts.

For most machines, the upgrade sequence is:

  • screwdriver (opens the maintenance panel)
  • Use RPED on target machine
  • screwdriver (closes the maintenance panel)

Some machines, such as gyroscopes or thrusters do not have a maintenance panel, and can be upgraded without additional requirements. Some machines, such as cooking ranges and reagent grinders, need to be crowbared into their deconstructed state before the RPED can be applied, then screwdrivered back to their finished state.

For each machine part used in the target machine, if the RPED contains a part of same type and higher rating, it will extract the old part and replace it with the new one. The old part is stored in the RPED. If the RPED is full, the part is left on top of the upgraded machine.

Upgradable machines[edit]

A machine which displays the upgrade symbol on its inspect description can be upgraded. The effect of upgrades depends on its function. For example, production machines usually increase material efficiency and time efficiency with component tiers.

Clicking the icon will bring up the upgrade details of the machine

List of non-upgradable machines which use upgradable components[edit]

Ship guns appear to be upgradable, but do not seem to have any change in their states or variables after upgrades. In addition, they are out-of-scope for most players, therefore are not listed.

The following machines are built using upgradable components, but do not benefit mechanically from being created with higher tier parts.

special cases:

  • Anomaly Vessel
  • Experimental Anomaly Vessel

while they have the upgrade icon, it is only used to indicate that the experimental version is 100% faster. They cannot be upgraded with parts.

  • Mobile EMP generator

While it has the upgrade icon, it is only used to show its use: 100m range, 1000 Kj absorbtion, 60s device deactivation. It cannot be upgraded with parts.

  • Shredder

While it has the upgrade icon, and list process rate as upgradable, it isn't built with manipulators and cannot be upgraded.

  • Biogenerator

The biogenerator used to accept upgrades using matter bins. Matter bins are no longer part of the construction recipe for the biogenerator. As a result, the biogenerator can no longer be upgraded.
